# Plan: a GitHub Pages site in nixarchy's style, with screenshots and a recording

This plan is self-contained: it carries every approved spec decision.

**Decisions**

- **A fork of nixarchy's site, as nixarchy-pkg did it.** The files are
  copied from nixarchy's `origin/main` `docs/`, not from pkg's copies.
  - `docs/assets/style.css` gets pkg's fork header. Only the `.logo`
    font-size clamp changes, marked `CHANGED FROM NIXARCHY'S COPY`.
  - `docs/assets/manual.js` is byte-identical.
  - `docs/_layouts/manual.html` changes only its titles and links.
  - `docs/_layouts/home.html` follows pkg's.
  - `docs/_includes/logo.html` is a figlet wordmark in
    `delta_corps_priest_1`, with `role="img"` and an `aria-label`.
- **The wordmark** is `PLUGINS` if it renders at most 92 columns wide,
  otherwise `PB`. The tagline carries the full name.
- **`docs/_config.yml`:** `title: nixarchy.plugin-browser`,
  `baseurl: /nixarchy-plugin-browser`, `include: [manual]`, the manual layout
  by default, and a `nav` in this order:
  1. index
  2. getting-started
  3. the-panel
  4. the-audit
  5. the-agent
  6. installing
  7. previews-and-privacy
  8. from-a-terminal
  9. troubleshooting
- **Pages:**
  - `docs/index.md` is the landing page: a pitch, the tour with its poster,
    three stills, and install links;
  - `docs/manual/*.md` are the nine pages above, with the content from the
    spec's table, rewritten from the README and the intent/spec/plan sets;
  - `docs/llms.txt` lists every page.
- **Media:**
  - captured on razer in its current theme (named in the captions), under
    ai-mirror control granted by the owner, recorded and announced;
  - stills are `docs/img/01-list … 10-add-plugin-row.webp`, cropped to the
    panel card, each under 200 KB;
  - the tour is `docs/img/tour.webm`, `tour.gif` (cropped, 12 fps, 960 px,
    palette pass, under 4 MB) and `tour-poster.webp`;
  - excluded: `o`, `c`, a real `y`, and any menu search;
  - tools: `nix run nixpkgs#imagemagick` and `nix run nixpkgs#ffmpeg`.
- **Publishing:** `.github/workflows/pages.yml` is pkg's workflow, with the
  deploy on `refs/heads/master`. It keeps the reachability check and the
  image-exists check, runs on PRs touching `docs/**`, and deploys on push.
  Pages is enabled after the merge with
  `gh api -X POST repos/olafkfreund/nixarchy-plugin-browser/pages -f build_type=workflow`.
- **The README** gains the site link and the tour GIF. **The flake is
  unchanged:** `docs/` is not in the `plugin` file list.
- **nixarchy** gets a follow-up PR after #915 merges, not now:
  - four media files under `docs/img/plugins/` and `docs/img/features/`;
  - the manual section's figures, caption and "its own site" link.

## Steps

1. **Scaffold** (`docs/_config.yml`, `_layouts/`, `_includes/logo.html`,
   `assets/`): copy nixarchy's files, add the fork header, and generate the
   wordmark. The font file is fetched once, pinned, from
   `xero/figlet-fonts`, and used with `nix run nixpkgs#figlet -- -d <dir>`;
   the output is committed text. Tune the clamp.
   → verify:
   - `diff` against nixarchy's `style.css` shows only the header and the
     marked clamp;
   - `manual.js` is byte-identical (`cmp`).
2. **Pages:** `docs/index.md`, the nine `docs/manual/*.md` pages and
   `docs/llms.txt`.
   → verify: the reachability script from `pages.yml`, run locally, passes
   (every page is in the nav, in llms.txt and in the index).
3. **Workflow:** `.github/workflows/pages.yml`.
   → verify: `nix run nixpkgs#actionlint` is clean, and the PR run is
   green, including the Jekyll build.
4. **Media on razer.** This happens in the same granted, recorded session
   as nixarchy #915's step-8 test, after the owner has logged in again. It
   is announced on the bus, and `gpu-screen-recorder` runs on eDP-1.
   Capture:
   - the stills in the spec's list, from ai-mirror screenshots cropped to
     the panel card;
   - the tour, recorded in one take, following the spec's script.

   Then convert and crop with ImageMagick and ffmpeg.
   → verify:
   - each still is under 200 KB and the GIF under 4 MB;
   - **every frame of the GIF and every still is reviewed for private
     data** (paths, tokens, notifications, clipboard, browser), with the
     review noted in the PR;
   - the image-exists check passes.
5. **README:** the site link and the tour GIF.
   → verify: the links resolve on the branch, and `nix flake check` passes
   (the package is unchanged; `nix path-info .#plugin` is the same before
   and after).
6. **Local render.** Build the site with the Pages action's Jekyll (or
   `nix run nixpkgs#jekyll -- build -s docs`), serve it, and screenshot the
   landing page and one manual page beside nixarchy's.
   → verify: the same look (fonts, colours, sidebar, logo treatment), with
   no broken image or link.
7. **PR #13:** link the three artifacts, mark it ready, and fast-forward
   master, as this repo does. Then enable Pages.
   → verify:
   - the deploy job is green;
   - https://olafkfreund.github.io/nixarchy-plugin-browser/ answers 200 and
     shows the tour.
8. **nixarchy follow-up** (after #915 merges): an issue with a milestone and
   label per nixarchy's rules, a branch, and a PR adding the four media
   files and the section's figures, caption and site link.
   → verify: its CI is green, including the manual-row and docs checks.

## Deviations recorded during implementation

- **Step 1: `docs/_layouts/home.html` is nixarchy's, not pkg's.** nixarchy has
  its own `home.html` (the spec assumed only pkg had one). The request is
  to look like nixarchy's site, and pkg's version adds a separate
  `home.css` and drops the masthead links. So nixarchy's is copied, with
  only its title and links changed, like `manual.html`.
- **Step 1: the font is pinned to xero/figlet-fonts `417429ef`** ("Delta
  Corps Priest 1.flf", sha256 `5065f00a…`), because nixpkgs' figlet does
  not ship it. By the same count, the wordmark `PLUGINS` is 75 columns and
  nixarchy's `NIXARCHY` is 93, so the clamp scales by 93/75:
  `clamp(0.3rem, 1.3vw, 1.09rem)`.
