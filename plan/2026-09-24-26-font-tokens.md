# Plan: The panel uses the same text sizes as the other nixarchy menus

This plan is self-contained; it carries every approved decision (intent
`f516513`, spec `a003861`). Line numbers are on `master` at `8da518c`; the
QML, `flake.nix` and `CHANGELOG.md` are unchanged on this branch.

**Decisions**

- **Body text is `Style.font.title` (option A).** All 16
  `font.pixelSize: Style.font.subtitle` lines become `Style.font.title`,
  including the header count, footer hint and dim detail lines:
  `BrowserView.qml:165 248 259 355 365 375 391 403 413 423 438 451 470` and
  `ShortcutSheet.qml:46 54 60`. Nothing else on those lines changes. After
  it the panel uses `heading` (card title, detail name, sheet title) and
  `title` (everything else, including the search field `:187`). Hierarchy
  stays with bold, colour and `dim`; colours, weights, `Text.PlainText`,
  elide and layout are untouched. Token sizes at base 12: `subtitle` 13,
  `title` 14, `heading` 16.
- **ShortcutSheet columns grow with the text:** group `Style.space(120)` →
  `Style.space(130)` (`:42`), keys `Style.space(220)` → `Style.space(240)`
  (`:50`). Longest labels at 14 px: `Anywhere` 67 px, `↑ ↓  Ctrl+K Ctrl+J`
  151 px; both keep a margin at every base size.
- **The sheet's "what" column wraps** (approver decision 6): the existing
  `Column` (`:20`) gets `id: rows`; the third `Text` (`:56-61`) gets
  `width: rows.width - Style.space(130) - Style.space(240) - 2 * Style.spacing.lg`,
  `wrapMode: Text.Wrap` and `textFormat: Text.PlainText`. The group and keys
  `Text`s keep fixed widths and do not wrap. At the card floor
  `Style.space(560)` the column is ~126 px (15 characters); the widest row
  wraps to 4 lines and no row runs past the card.
- **Accepted consequence (spec Risks):** on a card at its floor the wrapped
  sheet is ~785 px of rows in a ~388 px frame, and `frame` clips, so the last
  rows are hidden there. Implemented as decided; the owner's on-screen check
  decides whether a scrolling sheet becomes a follow-up issue.
- **`no-text-multiplier` check**, one script `tests/no-text-multiplier.sh
  [dir]` (`# tier: hermetic`): over every `*.qml` below the root (hidden
  dirs pruned), each `pixelSize:` / `fontSize:` binding, cut at `;` or `}`,
  must be a bare `Style.font.<name>` followed only by whitespace; `uiScale`,
  `textScale` and `px(` are refused anywhere in a `.qml`; no `.qml` found
  fails. It runs in a new flake check `no-text-multiplier` against `${self}`,
  inside `default` against the packaged copy, and in `tests/run.sh`.
  Accepted blind spots: a binding split over two lines, sizes set from
  `Model.js`. A trailing comment after a size token fails (deliberate).
  flatsnap's weaker regex is olafkfreund/nixarchy-flatsnap#21, not here.
- **One `CHANGELOG.md` line** under `## Unreleased`, after the #16 line.
- **Not changed:** `BarWidget.qml` (bar button and popup), `Menu.qml`,
  `Model.js`, keys, the package's `files` list. `docs/img/*`, `tour.gif`,
  `tour.webm` are retaken once by #16's step 11 after this merges.
- **No agent drives the live desktop.** The look is the owner's check.

## Steps

Each step is one commit, `fix(panel): … (#26)` or `test: … (#26)`, with the
session trailers.

1. **`tests/no-text-multiplier.sh`: new file, exactly the script in spec
   §3**, mode 644 like most tests (`run.sh` and the flake call it as `bash <file>`):

   ```bash
   #!/usr/bin/env bash
   # tier: hermetic
   #
   # tests/no-text-multiplier.sh [dir] — every text size in a QML file is a bare
   # Style.font.* token (#26): no factor, no uiScale/textScale/px() helper.
   # Prints "ok" and exits 0, or the offending lines and exits 1.
   set -uo pipefail
   ROOT=${1:-"$(cd -- "$(dirname -- "$0")/.." && pwd)"}
   # Hidden dirs below ROOT (.git, .claude/worktrees) are skipped; ROOT itself
   # may sit under one.
   mapfile -d '' qml < <(find "$ROOT" -mindepth 1 -name '.*' -prune -o -name '*.qml' -print0)
   [ ${#qml[@]} -gt 0 ] || { echo "no qml under $ROOT"; exit 1; }
   # Each pixelSize:/fontSize: binding, cut at ; or } so BarWidget.qml:148's
   # "...: Style.font.body; font.bold: true" is judged on its first binding.
   bad=$(grep -noHE '(pixelSize|fontSize):[^;}]*' "${qml[@]}" |
     grep -vE ':(pixelSize|fontSize):[[:space:]]*Style\.font\.[A-Za-z]+[[:space:]]*$')
   words=$(grep -nHE '\b(textScale|uiScale)\b|\bpx\(' "${qml[@]}")
   [ -z "$bad$words" ] || { printf '%s\n' "$bad" "$words" | sed '/^$/d'; exit 1; }
   echo ok
   ```

   → verify, RED first, on scratch copies of the tree (the tree itself is
   never mutated):

   ```bash
   S=$(mktemp -d); cp -r . "$S"
   sed -i '187s/Style\.font\.title/Style.font.title * 1.45/' "$S/BrowserView.qml"
   bash tests/no-text-multiplier.sh "$S"; echo "exit $?"
   ```

   → exit 1, prints `…/BrowserView.qml:187:pixelSize: Style.font.title * 1.45`.
   Repeat on fresh copies for `Math.round(Style.font.title * 1.45)` on `:187`,
   `; font.pixelSize: 20` appended to `BarWidget.qml:148`,
   `readonly property real uiScale: 1.45` added to `Menu.qml`, and the same
   with `textScale` and `px(12)`: each exits 1 and names its line. Then GREEN:
   `bash tests/no-text-multiplier.sh` on the tree → `ok`, exit 0 (the tree
   still has `subtitle`, which is a bare token). `rm -rf "$S"` after each.

3. **`ShortcutSheet.qml`: columns and the wrapping "what" column.**

   - `:42` `Style.space(120)` → `Style.space(130)`; `:50`

   - The third `Text` (`:56-61`) becomes:

     ```qml
     Text {
       width: rows.width - Style.space(130) - Style.space(240) - 2 * Style.spacing.lg
     ```

## Tests

Run from the repository root after step 5.

- **Tokens:** `grep -c 'Style.font.subtitle' BrowserView.qml ShortcutSheet.qml`
  → `BrowserView.qml:0`, `ShortcutSheet.qml:0`.
- **Check GREEN:** `bash tests/no-text-multiplier.sh` → `ok`, exit 0.
- **Check RED:** the step 1 scratch-copy commands → exit 1 for each of the
  six mutations, each naming its line.
- **Suite:** `bash tests/run.sh all` → every line `PASS`, including
  `PASS no-text-multiplier.sh`; exit 0. (Host-tier tests need the host's
  `/run/current-system/sw`; `bash tests/run.sh hermetic` is the subset the
  flake runs.)
- **Flake:** `nix flake check -L` → `default`, `files`, `hm-module` and
  `no-text-multiplier` all build; exit 0.
- **Sheet fit:** a one-off computation, not committed. Save as
  `$TMPDIR/fit.mjs` and run `node $TMPDIR/fit.mjs` from the repo root
  (or `nix run nixpkgs#nodejs -- $TMPDIR/fit.mjs`):

  ```js
  // Sheet fit at the card floor, base 12 (#26 spec decision 6).
  import { readFileSync } from "node:fs"
  import vm from "node:vm"
  const src = readFileSync("Model.js", "utf8").replace(/^\.pragma library\s*$/m, "")
  const M = {}; vm.runInNewContext(src + "\nM.S = SHORTCUTS", { M })
  const ch = 8.4, lh = 14 * 1.2308, frame = 560 - 2 * 16, rows = frame - 2 * 8
  const W = rows - 130 - 240 - 2 * 8, n = Math.floor(W / ch)
  const wrap = (s) => s.split(" ").reduce((a, w) => {
    const l = a[a.length - 1]
    if (l !== undefined && (l + " " + w).length <= n) a[a.length - 1] = l + " " + w; else a.push(w)
    return a }, [])
  let lines = 0, worst = 0, widest = ""
  for (const r of M.S) {
    const ls = wrap(r.what); lines += ls.length
    for (const l of ls) worst = Math.max(worst, l.length * ch)
    if (r.what.length > widest.length) widest = r.what
    console.log(`${ls.length}  ${r.keys.padEnd(18)} ${ls.join(" | ")}`)
  }
  console.log(`what width ${W} px (${n} chars); widest wrapped line ${worst.toFixed(0)} px`)
  console.log(`widest row unwrapped ${(130 + 8 + 240 + 8 + widest.length * ch).toFixed(0)} px vs rows ${rows} px: "${widest}"`)
  console.log(`height ~${Math.round(16 + 16 * 1.2308 + M.S.length * 3 + 12 + lines * lh)} px (${lines} lines) vs frame ~${420 - 32} px`)
  if (worst > W) { console.log("OVERFLOW"); process.exit(1) }
  console.log("wraps: every line fits")
  ```

  Expected (run while drafting this plan): `what width 126 px (15 chars);
  widest wrapped line 126 px`, `widest row unwrapped 764 px vs rows 512 px`,
  `f` wraps to 4 lines (`fix a copy with | your default | agent |
  (terminal)`), `height ~785 px (40 lines) vs frame ~388 px`,
  `wraps: every line fits`, exit 0. Constants: FiraCode Nerd Font (the
  machine's `fc-match monospace`) advance 0.6 em and line height 1.2308 em
  (hhea 1800 + 600 over 1950 upem); card floor 560 × 420; card content
  inset ~16 (popupPadding 14 + border 2); `spacing.lg` 8.
- **Manual, owner only:** open the panel at the default `base-size` and a
  large one. List, detail pane and footer are the size of the search field
  and of flatsnap's body text; `?` sheet keys labels are not truncated; long
  descriptions wrap inside the card; on the smallest screen in use, note
  whether the last sheet rows are clipped (spec Risks).

## Rollback

Everything is in the plugin's source and `flake.nix`; no state, no
migration. Revert the step commits (`git revert <step shas>`, newest first)
or, before merge, drop the branch. Reverting step 2 alone restores 13 px
body text and leaves the check in place (still green: `subtitle` is a bare
token). Reverting step 3 alone restores today's unwrapped sheet. The check
(steps 1 and 4) can be reverted on its own without touching the panel.
